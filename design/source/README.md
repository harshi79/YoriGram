# YoriGram source logo

Put the selected YoriGram PNG here with this exact filename:

```text
design/source/yorigram-logo.png
```

After that, run or ask the agent to run:

```bash
./tools/apply_yorigram_icon.sh
```

The script will generate the Windows `.ico`, app PNG sizes, macOS iconset PNGs, and the in-app default icon assets.
