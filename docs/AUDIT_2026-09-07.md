## Important limitations

A full Windows build was **not** performed in this Linux sandbox. YoriGram Desktop/AyuGram Desktop requires a Windows build environment with Visual Studio, Windows SDK, initialized submodules, prepared third-party libraries, and private Telegram API credentials.

So this audit verifies repository/source/icon consistency, but not a compiled `YoriGram.exe` binary.

## Where the exe will be after a Windows build

After following `docs/building-win.md`, the local executable should be at:

```text
D:\TBuild\tdesktop\out\Release\YoriGram.exe
```

Debug builds go to:

```text
D:\TBuild\tdesktop\out\Debug\YoriGram.exe
```

A push or merge alone does not create this file unless a Windows build/CI pipeline is run.
