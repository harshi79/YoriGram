# YoriGram Notice

YoriGram Desktop is a **personal-use, private rebrand experience** based on **AyuGram Desktop**.

The goal is to keep AyuGram Desktop's existing desktop Telegram functionality mostly unchanged while presenting a YoriGram-branded interface for a small, limited private user group.

## Personal-use intent

YoriGram is intended for private/personal use and experimentation by limited users. It is not intended to be a commercial product, a public replacement for Telegram Desktop, or an official Telegram client.

## Unofficial status

YoriGram is not affiliated with, endorsed by, sponsored by, or approved by Telegram, AyuGram, Radolyn Labs, or any other upstream maintainer.

## Upstream basis

This repository imports AyuGram Desktop as the stable base:

- Upstream repository: <https://github.com/AyuGram/AyuGramDesktop>
- Base version: `v7.0.9`
- Base commit: `032ad328549cff9f612d106d8660fbc03eb43130`

AyuGram Desktop itself is a fork of Telegram Desktop. YoriGram keeps upstream attribution and license obligations.

## Rebrand boundary

YoriGram may replace AyuGram names, icons, and UI labels in product-facing areas. Legal notices, copyright records, upstream credits, and license text must remain accurate and must not be removed simply for branding.
